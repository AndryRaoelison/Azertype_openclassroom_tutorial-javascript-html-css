# Azertype - Typing Game (OpenClassrooms Project)

Azertype is a simple typing game built with vanilla JavaScript, HTML, and CSS.  
This is an educational project, created as part of the OpenClassrooms web developer curriculum to practice key JavaScript concepts such as DOM manipulation, event handling

##  Objective : 

The goal of this project is to improve JavaScript skills by building an interactive game where users must type the displayed words as fast and accurately as possible.

##  Features : 

- Random word display
- Keystroke detection and validation
- Score tracking
- Basic error handling and feedback
- Responsive layout

##  Tech Stack :

- HTML5
- CSS3
- JavaScript (Vanilla)

# Azertype - Jeu de frappe au clavier (Projet OpenClassrooms)

Azertype est un jeu de dactylographie simple développé en JavaScript, HTML et CSS natifs.  
Il s'agit d'un projet éducatif réalisé dans le cadre du parcours développeur web d'OpenClassrooms, visant à pratiquer les concepts fondamentaux de JavaScript comme la manipulation du DOM et la gestion des événements clavier.

##  Objectif :

L'objectif de ce projet est d'améliorer ses compétences en JavaScript en créant un jeu interactif dans lequel l'utilisateur doit taper les mots affichés le plus rapidement et précisément possible.

##  Fonctionnalités :

- Affichage aléatoire de mots
- Détection et validation des frappes clavier
- Suivi du score
- Gestion d’erreurs et retours visuels de base
- Mise en page responsive

##  Technologies utilisées :

- HTML5  
- CSS3  
- JavaScript (Vanilla)
